# Azad News Photo Card — WordPress Plugin

[![WordPress](https://img.shields.io/badge/WordPress-5.0%2B-blue.svg)](https://wordpress.org)
[![PHP Version](https://img.shields.io/badge/PHP-7.4%2B-purple.svg)](https://php.net)
[![Version](https://img.shields.io/badge/Version-1.0.1-green.svg)](https://github.com/)
[![License](https://img.shields.io/badge/License-GPLv2-orange.svg)](https://www.gnu.org/licenses/gpl-2.0.html)

**Azad News Photo Card** হলো একটি আধুনিক ও শক্তিশালী ওয়ার্ডপ্রেস প্লাগইন, যা যেকোনো অনলাইন নিউজ পোর্টাল বা ব্লগের সিঙ্গেল পোস্ট থেকে সরাসরি এক ক্লিকে ফেসবুক, টুইটার ও ইনস্টাগ্রামের জন্য দৃষ্টিনন্দন **সোশ্যাল মিডিয়া ফটো কার্ড (Social Media Photo Card)** তৈরি এবং ডাউনলোড করতে সাহায্য করে।

---

## 🌟 প্রধান ফিচারসমূহ (Key Features)

- 🎨 **সিগনেচার ডিজাইন (Signature News Template)**:
  - উপরে আকর্ষণীয় ডার্ক মেরুন ডায়াগোনাল টেক্সচার এবং নিচে রয়্যাল ব্লু টর্ন পেপারের অরিজিনাল ব্যাকগ্রাউন্ড।
  - উপরে সেন্টারে বাংলা তারিখ বার (যেমন: `১১ জুলাই ২০২৬`)।
  - গোল্ডেন-ইয়েলো ডাবল বর্ডারযুক্ত ফিচার্ড ইমেজ ফ্রেম।
  - মাঝের মূল শব্দগুলোতে স্বয়ংক্রিয় গোল্ডেন-ইয়েলো (`#ffde00`) হাইলাইট সহ বোল্ড বাংলা হেডলাইন।
  - বৃত্তাকার `(আ)` লোগো আইকন ব্যাজ ও প্রতিবেদকের নাম (যেমন: `কক্সবাজার প্রতিনিধি:`)।
  - গ্লসি ব্লু গ্রেডিয়েন্ট বাটন ও সোনালী লেখা: **`বিস্তারিত কমেন্টে`**।
  - নিচে সাদা ফুটার ব্র্যান্ডিং বার: `আজাদ নিউজ ২৪ |`।

- 📍 **নিখুঁত বাটন প্লেসমেন্ট (Smart Placement)**:
  - প্রতিটি সিঙ্গেল পোস্ট পেজে ফিচার্ড ইমেজ ও পোস্ট মেটা তথ্যের ঠিক নিচে এবং মূল পোস্ট কনটেন্টের উপরে স্বয়ংক্রিয়ভাবে **Photo Card** বাটন বসে।
  - শর্টকোড ব্যবহারের সুবিধাও রয়েছে: `[azad_photo_card]`।

- 🎛️ **রিয়েল-টাইম কাস্টমাইজেশন পপআপ (Live Customize Modal)**:
  - **Title Font Size Slider**: ১৮px থেকে ৪২px পর্যন্ত টাইটেল ফন্ট সাইজ ছোট-বড় করার সুবিধা।
  - **Line Height Slider**: ১.০৫ থেকে ১.৯০ পর্যন্ত লাইনের স্পেসিং অ্যাডজাস্টমেন্ট।
  - **Bottom Text Font Size Slider**: ১৪px থেকে ৩০px পর্যন্ত বটম টেক্সট সাইজ কন্ট্রোল।
  - **Quick Edit Drawer**: ডাউনলোডের আগে সরাসরি পপআপ থেকেই শিরোনাম, প্রতিবেদক বা তারিখ পরিবর্তন করার সুবিধা।

- 📥 **আল্ট্রা হাই-রেজুলেশন ডাউনলোড (Ultra HD 2X Export)**:
  - ক্লায়েন্ট-সাইড `html2canvas` ইঞ্জিনের মাধ্যমে ক্রিস্টাল ক্লিয়ার **1200x1200px (বা 2160x2160px)** Ultra HD PNG কার্ড এক ক্লিকে ডাউনলোড হয়।
  - বাংলা ফন্টের সকল যুক্তাক্ষর (ক্ষ, ঙ্গ, জ্ঞ, ঞ্চ, ঞ্জ, ত্ত, থ, ণ্ড, ন্দ ইত্যাদি) নিখুঁতভাবে রেন্ডার হয়।

- ⚙️ **ওয়ার্ডপ্রেস এডমিন সেটিংস ড্যাশবোর্ড (Admin Dashboard)**:
  - ওয়ার্ডপ্রেস এডমিন মেনুতে নিজস্ব ডেডিকেটেড মেনু: **Azad Photo Card**।
  - সরাসরি মিডিয়া লাইব্রেরি থেকে লোগো ও আইকন আপলোড/পরিবর্তন।
  - ডিফল্ট ফন্ট সাইজ, লাইন হাইট, বাংলা ফন্ট ফ্যামিলি (`Hind Siliguri`, `Noto Serif Bengali`, `Tiro Bangla` ইত্যাদি) কনফিগারেশন।
  - এডমিন প্যানেলেই **লাইভ প্রিভিউ ও টেস্ট কার্ড জেনারেটর**।

- 📅 **অটোমেটিক বাংলা তারিখ ও সংখ্যা কনভার্টার**:
  - পোস্টের ইংরেজি পাবলিশ ডেট ও ডিজিটকে স্বয়ংক্রিয়ভাবে বাংলায় রূপান্তর করে (যেমন: `11 July 2026` -> `১১ জুলাই ২০২৬`)।

## 🚀 ইনস্টলেশন গাইড (Installation)

### মেথড ১: ওয়ার্ডপ্রেস ড্যাশবোর্ড থেকে (ZIP Upload)
1. এই রিপোজিটরি থেকে `azadnews-photo-card.zip` ফাইলটি ডাউনলোড করুন।
2. আপনার WordPress Admin Panel-এ লগইন করুন।
3. **Plugins** -> **Add New** -> **Upload Plugin**-এ ক্লিক করুন।
4. `azadnews-photo-card.zip` ফাইলটি সিলেক্ট করে **Install Now** এবং তারপর **Activate Plugin** বাটনে চাপুন।

### মেথড ২: ম্যানুয়ালি / গিট ক্লোন করে (Manual / Git Clone)
আপনার ওয়ার্ডপ্রেসের প্লাগইন ফোল্ডারে রিপোজিটরিটি ক্লোন করুন:
```bash
cd wp-content/plugins/
git clone https://github.com/your-username/azadnews-photo-card.git
```
এরপর WordPress Admin -> **Plugins**-এ গিয়ে প্লাগইনটি **Activate** করুন।

## ⚙️ কনফিগারেশন ও ব্যবহার (How to Use)

1. প্লাগইন অ্যাক্টিভ করার পর বাম পাশের মেনু থেকে **Azad Photo Card**-এ যান।
2. **ব্র্যান্ডিং ও লোগো** ট্যাব থেকে আপনার সাইটের লোগো আইকন এবং ফুটার টেক্সট সেট করুন।
3. **টাইপোগ্রাফি ও ডিফল্ট** ট্যাব থেকে ডিফল্ট Title Font Size, Line Height এবং ফন্ট সিলেক্ট করে সেটিংস সংরক্ষণ করুন।
4. এবার ওয়েবসাইটের যেকোনো সিঙ্গেল পোস্টে প্রবেশ করলেই ফিচার্ড ইমেজের ঠিক নিচে **Photo Card** বাটন দেখতে পাবেন।
5. বাটনে ক্লিক করলে লাইভ পপআপ ওপেন হবে। স্লাইডার টেনে ফন্ট সাইজ অ্যাডজাস্ট করে **Download Photo Card** বাটনে চাপলেই ইমেজ ডাউনলোড হয়ে যাবে!
