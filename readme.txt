Azad News-24 এর জন্য তৈরি আধুনিক সোশ্যাল মিডিয়া ফটো কার্ড জেনারেটর প্লাগইন।

== Description ==

**Azad News Photo Card** প্লাগইনটির মাধ্যমে আপনার নিউজ পোর্টালের যেকোনো সিঙ্গেল পোস্ট থেকে সরাসরি এক ক্লিকে দৃষ্টিনন্দন ও হাই-রেজুলেশন ফটো কার্ড তৈরি এবং ডাউনলোড করা যাবে।

### প্রধান ফিচারসমূহ:
* **সিঙ্গেল পোস্ট ইন্টিগ্রেশন**: স্বয়ংক্রিয়ভাবে বা শর্টকোড `[azad_photo_card]` দিয়ে ফটো কার্ড বাটন যুক্ত করা যায়।
* **লাইভ কাস্টমাইজেশন পপআপ**:
  - লাইভ **Title Font Size** স্লাইডার (১৮px থেকে ৪২px)।
  - লাইভ **Line Height** স্লাইডার (১.০৫ থেকে ১.৯)।
  - লাইভ **Bottom Text Font Size** স্লাইডার (১৪px থেকে ৩০px)।
  - রিয়েল-টাইম প্রিভিউ দেখে **Download Photo Card** বাটনে চাপলেই ইমেজ ডাউনলোড হবে।
* **একাধিক ডিজাইন টেমপ্লেট**:
  - **টেমপ্লেট ১ (Blue Wave)**: কার্ভড ডেট পিল, ইয়েলো ফ্রেম, ব্লু গ্লোয়িং কমেন্ট ব্যাজ।
  - **টেমপ্লেট ২ (Red Brand)**: আজাদ নিউজ ২৪ হেডার লোগো, স্পেশাল কর্নার কার্ভ ফ্রেম ও ডার্ক রেড ব্যাকগ্রাউন্ড।
  - **টেমপ্লেট ৩ (Dark Gold)**: প্রিমিয়াম ডার্ক গোল্ড ব্রেকিং নিউজ এডিশন।
* **অ্যাডমিন ড্যাশবোর্ড সেটিংস**:
  - লোগো ও আইকন আপলোড।
  - ডিফল্ট ফন্ট সাইজ, লাইন হাইট, ফন্ট ফ্যামিলি (`Hind Siliguri`, `Noto Serif Bengali`, `Tiro Bangla`)।
  - অটোমেটিক বাংলা তারিখ কনভার্টার (যেমন: `১১ জুলাই ২০২৬`)।
  - এক্সপোর্ট কোয়ালিটি কন্ট্রোল (Ultra HD 2X Retina 2160x2160px)।

== Installation ==

1. প্লাগইন ফাইলটি ডাউনলোড করে আপনার WordPress Dashboard -> Plugins -> Add New -> Upload Plugin-এ যান।
2. `azadnews-photo-card.zip` ফাইলটি আপলোড করে **Activate** করুন।
3. **Azad Photo Card** মেনু থেকে আপনার লোগো এবং ডিফল্ট সেটিংস কনফিগার করুন।
4. যেকোনো সিঙ্গেল পোস্টে গিয়ে ফটো কার্ড তৈরি ও ডাউনলোড করুন।
